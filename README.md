# Sree Sree Reading Hall Web Application

A modern, high-performance web application built for **Sree Sree Reading Hall** (Tirupati).

## 🚀 Tech Stack
- **Frontend**: React 18, TypeScript, Vite, Tailwind CSS, Lucide Icons
- **Backend (API)**: PHP PDO REST Endpoints
- **Database**: MySQL

## 📖 Features
- **Interactive Visual Seat Reservation**: Visual 48-desk layout grid with AC/Non-AC zone filters and shift selection (Morning, Evening, Full Day, Night).
- **Facilities Showcase**: Wifi, AC, RO Water, Quiet Study Bays, Power Sockets, Dining Lounge, Washrooms.
- **Photo Tour Lightbox**: Authentic high-resolution gallery of Sree Sree Reading Hall.
- **Blog System**: Knowledge articles, search, category filters, and full reader modal.
- **Admin Dashboard**: Preview portal for managing seat allocations, blog posts, and lead inquiries.
- **Location & WhatsApp Integration**: Tirupati Axis Bank Plaza address, map, and instant click-to-chat.

## 🛠️ Local Development
```bash
# Install dependencies
npm install

# Run dev server
npm run dev

# Build for production
npm run build
```
